## Overview

The new front-end uses React and shadcn/ui technology stacks, aiming to provide a more modern, responsive and beautiful user interface.


## Technology Stack

* React
* TypeScript
* shadcn/ui (based on Radix UI and Tailwind CSS)
* pnpm (package manager)
* axios (HTTP request)
* react-router-dom (router)
* xterm.js (terminal simulation)
* react-dropzone (file upload drag and drop)
* sonner (notification)

## Project Structure

```
ansible-react-frontend/
├── public/ # Static resources (favicon, etc.)
├── src/
│ ├── components/ # Reusable UI components (including components generated by shadcn/ui)
│ │ ├── ui/ # shadcn/ui Basic Components
│ └── FileUpload.tsx # FileUpload component
│ ├── contexts/ # React Context (for example, AuthContext)
│ ├── pages/ # Page-level components (LoginPage, MainPage, TerminalPage)
│ ├── services/ # API service encapsulation (api.ts)
│ ├── App.tsx # Apply the main component and handle routing
│ ├── index.css # Global style (Tailwind CSS basic style)
│ └── main.tsx # Application entry point
├── index.html # HTML entry file
├── package.json # Project dependencies and scripts
├── pnpm-lock.yaml # Depend on locking files
├── tsconfig.json # TypeScript Configuration
├── tsconfig.node.json # TypeScript Node Configuration
└── vite.config.ts # Vite configuration file
```
